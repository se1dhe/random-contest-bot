The problem

Classic contest bots often feel outdated and opaque for both admins and participants.

  • Text-only interfaces look old and reduce trust.
  • Participants cannot see live registration dynamics or draw timing.
  • Admins manually verify subscriptions across Telegram, YouTube, and TikTok.
  • No analytics — growth and contest performance stay invisible.

Our solution

Random Contest Bot 2.0 is a full web application embedded in Telegram. Each owner runs their own instance and controls access via ADMIN_ID / ADMIN_IDS.

✨

Native app feel

SPA with glassmorphism, Framer Motion transitions, confetti, and second-accurate countdown timers.

📡

Radical transparency

Live participant counter via WebSockets and instant visual feedback on condition checks.

🛠

All tools in one place

Full GUI admin panel — no slash commands. Channels, sponsors, prizes, and analytics in a few taps.

Full feature set

Everything needed to launch, run, and analyze community giveaways.

Participant registration

Contest page with conditions, captcha, paid entry via Telegram Stars, OAuth for YouTube/TikTok, and real-time status updates.

Multi-platform verification

Telegram channel/group subscription, YouTube channel follow (Google OAuth), TikTok follow, sponsor channels, and forum topics.

Admin dashboard

Overview, contests, archive, audit journal, and channel management with bulk publish, CSV export, and post preview.

Contest lifecycle

Draft → active → finished → results. Scheduled publish/end via Redis, random or activity-based draw, republish and repair tools.

Results & celebration

Winner announcement page with confetti, public results deep links, and automatic channel publication from the bot.

Analytics & health

Growth charts, overview metrics, system health panel, and admin action log for full operational visibility.

Localization

Contest UI in RU / UK / EN with per-contest language selection for international communities.

Self-hosted & secure

Docker Compose deployment, PostgreSQL + Redis, Telegram initData auth, admin-only API, and OAuth limited-use policies.
