# Random Contest Bot 2.0: Презентация проекта

## 🎯 Видение
Дать администраторам отдельную self-hosted копию бота для проведения розыгрышей в Telegram: без общей SaaS-платформы, подписок внутри продукта и зависимости от чужой админки.

---

## 🛑 Проблема
Обычные боты для конкурсов часто обладают недостатками:
1.  **Скучно**: Текстовые интерфейсы выглядят устаревшими.
2.  **Непрозрачно**: Пользователи не видят, кто еще зарегистрировался и когда происходит розыгрыш.
3.  **Ручной труд**: Администраторы мучаются с проверкой подписок на разных платформах (Telegram + YouTube).
4.  **Слепота**: Отсутствие аналитики не дает понять динамику роста канала.

---

## ✅ Решение
**Random Contest Bot 2.0** работает как полноценное веб-приложение, встроенное в Telegram.
Каждый клиент получает собственный экземпляр для установки на свой сервер и управляет доступом через `ADMIN_ID`/`ADMIN_IDS`.

### 1. "Вау"-эффект
*   Ощущение нативного приложения (Single Page Application).
*   Живые таймеры обратного отсчета, синхронизированные до секунды.
*   Анимация определения победителя (Конфетти, плавные переходы).
*   Премиальный дизайн в стиле глассморфизм.

### 2. Радикальная прозрачность
*   **Живой счетчик**: Участники видят, как число регистраций растет в реальном времени (WebSockets).
*   **Мгновенная проверка**: Бот проверяет подписки сразу же и дает визуальную обратную связь.

### 3. Все инструменты в одном месте
*   Никаких `/команд`.
*   Полноценная **Админ-панель** (GUI).
*   Управление каналами, спонсорами и призами в пару касаний.
*   **Аналитика**: Графики роста и эффективность конкурсов прямо в приложении.

---

## 🏗 Техническая архитектура

### Подход "Frontend-First"
В отличие от традиционных ботов, генерирующих HTML на сервере или отправляющих текст, мы используем **React**.
*   **SPA Архитектура**: Приложение загружается один раз и работает плавно.
*   **FastAPI Бэкенд**: Надежный REST API + WebSocket сервер.
*   **Redis**: Мост между событиями Python бэкенда и React фронтенда.

### Стек
*   **Фронтенд**: React, Vite, TailwindCSS, Framer Motion, Recharts.
*   **Бэкенд**: Python, FastAPI, SQLAlchemy, Aiogram.
*   **База данных**: PostgreSQL.
*   **DevOps**: Docker Compose для развертывания одной командой.

## 📈 Ценность для бизнеса
*   **Рост вовлеченности**: Пользователи проводят больше времени в приложении.
*   **Высокая конверсия**: Удобные кнопки проверки подписки снижают трение.
*   **Отслеживание роста**: Аналитика помогает оптимизировать проведение конкурсов.
