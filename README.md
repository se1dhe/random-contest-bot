**Профессиональная платформа для автоматического проведения розыгрышей в Telegram, построенная как Web App (TWA).**

Этот бот революционизирует проведение конкурсов, объединяя мощный Python-бэкенд с красивым и реактивным современным интерфейсом. Забудьте о ручных проверках и текстовых командах — наслаждайтесь обновлениями в реальном времени, визуальными таймерами и мгновенным определением победителей.

---

## ✨ Ключевые возможности

### 🎮 Интерактивное веб-приложение (SPA)
*   **Бесшовная интеграция**: Работает полностью внутри Telegram через платформу Mini Apps.
*   **Реальное время**: WebSocket интеграция обеспечивает мгновенное обновление счетчиков участников и статусов.
*   **Визуальный стиль**: Премиальный UI/UX в стиле глассморфизма с плавными анимациями (Framer Motion) и эффектами конфетти.

### 🛡️ Админ-панель
*   **Полный контроль**: Создавайте, редактируйте и управляйте конкурсами прямо из интерфейса Telegram.
*   **Управление каналами**: Расширенные операции добавления и удаления Telegram и YouTube каналов с проверкой прав администратора в реальном времени.
*   **Аналитика**: Визуальные графики, отслеживающие рост аудитории и вовлеченность в конкурсы.

### ⚙️ Мощная механика
*   **Мультиплатформенность**: Обязательная подписка как на Telegram каналы (через Bot API), так и на YouTube каналы (через OAuth/API).
*   **Честность и прозрачность**: Случайный выбор победителя с использованием криптографически надежных методов.
*   **Умная валидация**: Автоматическая проверка подписки для создания прозрачных конкурсов без накруток.

## 🛠️ Технологический стек

### Бэкенд (Backend)
*   **Язык**: Python 3.11
*   **Фреймворк**: FastAPI (Высокопроизводительный асинхронный API)
*   **База данных**: PostgreSQL + SQLAlchemy (Async ORM)
*   **Бот**: Aiogram 3.x (Современная обертка для Telegram API)
*   **Очереди**: Redis (Pub/Sub для событий реального времени)

### Фронтенд (Frontend)
*   **Фреймворк**: React 18 + Vite (Сверхбыстрая сборка)
*   **Стили**: TailwindCSS (Utility-first) с кастомной дизайн-системой.
*   **Состояние**: React Query (TanStack Query) для эффективной работы с API.
*   **Анимации**: Framer Motion для жестов и переходов.
*   **Визуализация**: Recharts для аналитических данных.

### Инфраструктура
*   **Контейнеризация**: Docker & Docker Compose
*   **Сервер**: Nginx (Reverse proxy)
